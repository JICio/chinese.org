# Chinese.org

面向全球华人、特别是海外华人的文化传播与共建平台。项目记录华人故事，整理华夏文明知识，连接世界各地社区，并支持下一代以双语和新的创作形式继续发展文化。

## 内容架构

- 全球华人：迁徙、家庭、身份、社区与青年创作
- 华夏文明：思想宇宙、生命身体、艺术生活、历史地方、技艺传承
- 文化画廊：专题策展、作品资料、作者署名、来源与授权记录
- 文化地图：全球城市、社团、学校、文化空间与活动
- 文化连接：隐私优先的同城、同乡、姓氏、方言与兴趣社区
- 社区共治：提问、编辑、核查、多语发布与公开修订流程
- 共建计划：故事投稿、知识贡献、翻译、事实核查与城市连接
- 汉字练习室：保留原有笔顺、语音、纠错与唐诗练习工具

## 本地运行

这是一个无构建步骤的静态网站。在项目目录运行：

```bash
python3 -m http.server 4173
```

然后打开 `http://localhost:4173`。

## 部署

可直接部署到 GitHub Pages、Cloudflare Pages、Netlify 或任意静态文件服务器。

## 数据与依赖

- [Hanzi Writer](https://hanziwriter.org/) 用于汉字练习室的笔顺动画与测验
- OpenCC 用于繁简转换
- 本仓库包含简体字笔画编码与唐诗三百首的本地数据文件
