# Chinese.org

一个打开即练的互动汉字写字教练，帮助学习者掌握笔顺、笔画名称、汉字结构、偏旁与唐诗。

## 功能

- 汉字笔顺动画与跟写纠错
- 普通话笔画语音提示
- 学习数据、薄弱笔画与自适应练习
- 偏旁、结构、难字与唐诗关卡
- 分级考试与自选汉字
- 桌面、平板与手机响应式界面

## 本地运行

这是一个无构建步骤的静态网站。在项目目录运行：

```bash
python3 -m http.server 4173
```

然后打开 `http://localhost:4173`。

## 部署

可直接部署到 GitHub Pages、Cloudflare Pages、Netlify 或任意静态文件服务器。

## 数据与依赖

- [Hanzi Writer](https://hanziwriter.org/) 用于笔顺动画与测验
- OpenCC 用于繁简转换
- 本仓库包含简体字笔画编码与唐诗三百首的本地数据文件
