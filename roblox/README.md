# 金光神咒 · Roblox 漢字收集遊戲

在地圖裡尋找漢字與偏旁部件，按順序拼出《金光神咒》前八句（32 字）。

## 玩法

- **金色方塊** = 整字，撿到就是它
- **綠色方塊** = 偏旁部件（土、也、礻、申、犭、虫……），湊齊一個字的兩個部件自動拼成整字
  （可拼的字：地 根 亿 劫 证 神 外 惟 独 体 映）
- 必須**按咒文順序**收集：頂部 HUD 顯示進度——金色已收、紅色是下一個目標、綠色提示可拼的部件
- 拼完 32 字：**金光護體**（金光 + 火花 + 護盾 15 秒 + 加速），全服廣播，排行榜「神咒」+1，然後從頭再修一遍

## 打開方式

1. 打開 Roblox Studio
2. File → Open from File →選 `金光神咒.rbxlx`
3. 點 ▶ Play 即可單人試玩；Alt+點 Play 旁的下拉可開多人測試（Local Server + 2 Players）
4. 滿意後 File → Publish to Roblox 發佈，就能和朋友聯機

## 文件結構

- `Workspace`：地板 + 出生點（拾取物由腳本動態生成，常駐約 45 個）
- `ServerScriptService/MantraServer`：拾取生成、碰撞收集、拼字判定、金光慶祝、排行榜
- `StarterPlayer/StarterPlayerScripts/MantraHUD`：頂部咒文進度條、部件提示、飄字通知

## 咒文

天地玄宗，万气本根。广修亿劫，证吾神通。
三界内外，惟道独尊。体有金光，覆映吾身。
